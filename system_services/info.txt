حوه استفاده:
فایل‌ها را دانلود و به Raspberry Pi منتقل کن.

کپی به /etc/systemd/system/:

bash
Copy
Edit
sudo cp friseurbot-*.service /etc/systemd/system/
فعال‌سازی:

bash
Copy
Edit
sudo systemctl daemon-reexec
sudo systemctl daemon-reload
sudo systemctl enable friseurbot-backend.service
sudo systemctl enable friseurbot-frontend.service
sudo systemctl enable friseurbot-bot.service
اجرای همه:

bash
Copy
Edit
sudo systemctl start friseurbot-backend
sudo systemctl start friseurbot-frontend
sudo systemctl start friseurbot-bot
🕵️ مانیتورینگ:
bash
Copy
Edit
# بررسی وضعیت
sudo systemctl status friseurbot-bot

# مانیتورینگ لحظه‌ای لاگ‌ها
journalctl -u friseurbot-frontend -f
هر زمانی خواستی مسیر پروژه یا یوزر را تغییر بدی، فقط داخل فایل .service مسیر را به‌روزرسانی کن و بزن:

bash
Copy
Edit
sudo systemctl daemon-reload
اگر بخوای فایل .env هم لود بشه یا پورت خاصی ست کنی، می‌تونم اونم برات تنظیم کنم.
