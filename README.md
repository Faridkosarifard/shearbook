# Friseurbot

💈 **Friseurbot** is a complete system for managing appointments, services, stylists, and customer management for beauty salons. This project is built using **Python (Flask)** for the backend and **React + Tailwind + Vite** for the frontend.

## 📦 Features
- Manage appointments with add, edit, and delete capabilities
- Calendar view with weekly and daily displays
- Manage services and control their display order
- Manage stylists with active/inactive toggle
- Configurable settings (business hours, days off, message texts)
- Automatic reminder message sending
- Modern, responsive user interface
- CLI for server and project management

## 🚀 Installation & Setup

### Backend (Python + Flask)

1️⃣ Install dependencies:
```bash
poetry install
```

2️⃣ Run the server:
```bash
poetry run python app.py
```

### Frontend (React + Vite)

1️⃣ Install dependencies:
```bash
npm install
```

2️⃣ Start the project:
```bash
npm run dev
```

## ⚙️ Configuration
- Backend settings: `config.py`
- Frontend development setup: `vite.config.js`

## 💡 Tech Stack
- Flask (Python) → API and data management
- React + Tailwind → Fast, modern UI
- PostgreSQL → Database
